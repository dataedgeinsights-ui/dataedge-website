Document Library

Keep a categorised register of every document tied to this assignment. This stores the record (title, category, status, notes, and a link to where the actual file lives), not the file itself, since this workbench only holds text data, not attachments. Keep the real files in Drive or SharePoint and link to them here.

Google Drive sync

Creates a real folder in your connected Google Drive named "DataEdge Insights - Evaluation Library," with a subfolder for each category below. Once synced, each document record gets a "Save to Drive" option that files a metadata record into the matching folder and links back to it here. This does not upload the actual file bytes (Word docs, PDFs); it keeps the real files exactly where you already store them and gives this workbench a live, clickable pointer into Drive.
